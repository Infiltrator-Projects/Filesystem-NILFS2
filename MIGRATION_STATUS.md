# NILFS2 Common V2 migration

The native offline reader implements committed super-root bootstrap, physical DAT and virtual mapping, checkpoint ifile resolution, allocator ownership and segment accounting, CORE probe/mount/stat/list/read and VOLUME query for the bounded baseline profile. [Development CI 46133559995](https://github.com/Infiltrator-Projects/Filesystem-NILFS2/actions/runs/46133559995) passed the real formatter namespace, structural sparse/payload fixtures and sanitizer checks. Independent populated-media qualification is now mandatory: a separate reference implementation creates a disposable image, unmounts it, and both native providers compare data with the original exported bytes and verify the unchanged image hash.

No runtime release before the populated gate succeeds; the existing v0.0.1 remains PDF-only. Snapshot selection, replay, cleaning, mutation, defragmentation, physical BOOT/kernel integration remain outstanding. The [pinned format source](https://github.com/Infiltrator-Projects/Filesystems/tree/101026021d9088d80b7f0f472d9061f0e2c688a3/native/filesystems/nilfs2) is a reference, not a runtime backend.
